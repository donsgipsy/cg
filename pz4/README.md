
## Управление
ЛКМ — стена; ПКМ или E+ЛКМ — стереть; S+ЛКМ — START; G+ЛКМ — GOAL; W+ЛКМ — клетка со стоимостью 5.
1/2/3 — BFS/Dijkstra/A*; SPACE — старт/пауза; N — шаг; R — сброс поиска; C — очистка карты;
↑/↓ — скорость; 4–9 — тестовые сценарии; P — скриншот; Esc — выход.

## Структура
main.py — event loop и управление; algorithms.py — BFS, Dijkstra, A*, heuristic (без PyGame);
grid.py — сетка, соседи, стоимости, редактирование; visualizer.py — отрисовка;
settings.py — константы; scenarios.py — тестовые карты; screenshots/ — скриншоты.

## Идея
Алгоритмы — генераторы с yield: каждый кадр event loop вызывает next(), поэтому поиск
идёт во время визуализации. Путь восстанавливается через came_from от GOAL к START.
Пауза останавливает только шаги алгоритма, но не event loop.

## Статистика
Visited nodes — обработанные клетки; Path length — число переходов; Path cost — сумма
стоимостей клеток маршрута; Steps — шаги генератора; Frontier size; Search time.
