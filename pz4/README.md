# Визуализация алгоритмов поиска пути

## Что сделано

Разработано интерактивное приложение на Python + PyGame для пошаговой визуализации поиска пути на сетке.

- Реализованы алгоритмы: BFS, Dijkstra, A*.
- Добавлено редактирование карты: стены, старт, цель и взвешенные клетки («болота» со стоимостью 5).
- Настроена анимация процесса поиска и подсветка итогового маршрута.
- Соблюдено разделение архитектуры: алгоритмы работают с чистыми данными и не импортируют PyGame.

## Управление

### Клавиатура

- `1`, `2`, `3` — выбрать алгоритм (BFS, Dijkstra, A*)
- `Пробел` — старт / пауза
- `N` — сделать один шаг
- `R` — очистить результат поиска
- `C` — очистить всю карту
- `↑` / `↓` — увеличить / уменьшить скорость
- `Esc` — выход

### Мышь

- `ЛКМ` — поставить стену
- `ПКМ` — стереть клетку
- `S` + `ЛКМ` — установить старт
- `G` + `ЛКМ` — установить цель
- `W` + `ЛКМ` — установить дорогую клетку
