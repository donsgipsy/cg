# Редактор аффинных преобразований

Интерактивный редактор аффинных преобразований на Python + PyGame. Позволяет управлять геометрической фигурой («домик») через матрицы 3×3 и наблюдать результат в реальном времени.

## Что сделано

- Создано приложение с координатной сеткой, осями и информационной панелью.
- Реализован составной объект «домик» из четырёх многоугольников (корпус, крыша, дверь, окно).
- Написаны функции для всех базовых матриц: перенос, масштаб, поворот, отражение, shear.
- Добавлена поддержка двух режимов композиции: `T @ R` и `R @ T`.
- Реализован поворот вокруг произвольной точки (pivot).
- Выделение объекта мышью через обратную матрицу и проверку попадания в полигон (ray casting).
- Соблюдено разделение архитектуры: `transformations.py` не импортирует PyGame.

## Управление

### Клавиатура

| Клавиша | Действие |
|---------|----------|
| `←` `→` `↑` `↓` | Перемещение объекта |
| `Q` / `E` | Поворот (против/по часовой) |
| `Z` / `X` | Масштаб по X (уменьшить/увеличить) |
| `A` / `D` | Масштаб по Y |
| `J` / `L` | Shear по X |
| `U` / `O` | Shear по Y |
| `H` | Отражение по вертикальной оси |
| `V` | Отражение по горизонтальной оси |
| `M` | Переключение режима композиции (TR ↔ RT) |
| `R` | Сброс всех преобразований |
| `Esc` | Выход |

### Мышь

| Действие | Результат |
|----------|-----------|
| ЛКМ по объекту | Выделить/снять выделение |
| `P` + ЛКМ | Установить опорную точку (pivot) |

## Демонстрация

1. **Перенос:** нажмите стрелки — домик двигается, матрица обновляется.
2. **Поворот:** нажмите `E` несколько раз — домик вращается вокруг красной точки (pivot).
3. **Масштаб:** нажмите `X` — домик растягивается по ширине.
4. **Shear:** нажмите `L` — домик «наклоняется» вправо.
5. **Отражение:** нажмите `H` — домик зеркально отражается.
6. **Режим композиции:** нажмите `M` — переключается между `T@R` и `R@T`, результат меняется.
7. **Pivot:** нажмите `P` и кликните мышью — красная точка перемещается, теперь вращение идёт вокруг неё.
8. **Выделение:** кликните по домику — он становится оранжевым.
9. **Сброс:** нажмите `R` — всё возвращается в исходное состояние.

## Ключевые особенности

- **Однородные координаты:** все преобразования описываются матрицами 3×3.
- **Композиция матриц:** порядок умножения важен (`T@R ≠ R@T`).
- **Обратная матрица:** используется для перевода координат мыши в локальную систему объекта.
- **Ray casting:** проверка попадания точки в многоугольник по алгоритму пересечения луча.
- **Независимость от FPS:** скорость перемещения и вращения зависит от `dt`, а не от частоты кадров.
