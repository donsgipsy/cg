## Описание проекта
Интерактивное приложение на Python + PyGame, которое пошагово визуализирует работу трёх алгоритмов:
- Пузырьковая сортировка (Bubble Sort)
- Сортировка выбором (Selection Sort)
- Бинарный поиск (Binary Search)

Приложение показывает не только результат, но и каждое промежуточное состояние алгоритма с цветовой подсветкой.

### 1. Окно и интерфейс
- Окно 1200×750 пикселей, 60 FPS
- Область визуализации массива столбцами
- Название текущего алгоритма
- Панель статистики (Comparisons, Swaps, Pass, Steps)
- Легенда цветов (9 состояний)
- Подсказки по управлению внизу экрана
- Корректное завершение по Esc и крестику окна

### 2. Исходный массив
- 30 случайных чисел от 30 до 100
- Клавиша **R** генерирует новый массив
- Новый массив не создаётся во время работы алгоритма без сброса

### 3. Графическое представление
- Каждый элемент — вертикальный столбец
- Высота пропорциональна значению
- Столбцы равномерно распределены
- Числовые значения отображаются над столбцами

### 4. Визуальные состояния (9 цветов)
- **Синий** — обычный элемент
- **Жёлтый** — сравниваемые элементы
- **Красный** — элементы при обмене
- **Оранжевый** — найденный минимум
- **Зелёный** — отсортированный / найденный элемент
- **Голубой** — активный диапазон поиска
- **Фиолетовый** — mid (середина)
- **Серый** — исключённый из поиска элемент

### 5. Пузырьковая сортировка (Bubble Sort)
- Пошаговая визуализация сравнений соседних элементов
- Подсветка факта обмена
- Отметка элементов, занявших окончательную позицию
- **Оптимизация раннего завершения**: если за проход не было обменов — сортировка останавливается досрочно

### 6. Сортировка выбором (Selection Sort)
- Визуальное разделение отсортированной и неотсортированной частей
- Подсветка текущего проверяемого элемента
- Подсветка индекса минимального найденного элемента
- Анимация обмена минимума с началом рабочей области

### 7. Бинарный поиск (Binary Search)
- Работает только по отсортированному массиву (используется отдельная отсортированная копия)
- Визуализация left, mid, right на каждом шаге
- Подсветка активного диапазона и исключённых элементов
- Два режима: элемент найден / элемент не найден
- Выбор target стрелками ВВЕРХ/ВНИЗ (листает элементы массива) или клавишей **T** (случайное значение)

### 8. Управление
- **1** — Bubble Sort
- **2** — Selection Sort
- **3** — Binary Search
- **SPACE** — запуск / пауза
- **N** — выполнить один шаг
- **R** — новый массив / сброс
- **ВВЕРХ/ВНИЗ** — изменить target (в режиме бинарного поиска)
- **T** — случайный target (в режиме бинарного поиска)
- **ESC** — выход

### 9. Статистика
- **Bubble Sort / Selection Sort**: Comparisons, Swaps, Pass, Steps
- **Binary Search**: Target, Comparisons, Steps, Current range, Result
- Статистика сохраняется на экране после завершения до сброса
